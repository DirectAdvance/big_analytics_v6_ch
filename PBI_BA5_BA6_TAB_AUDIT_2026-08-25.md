## Вывод

Главные проблемы переноса не в общих метриках, а в BI-слое:

1. `pages.json` BA6 содержит битые ссылки на страницы.
2. Верхние панели Я.Директа сдвинуты после удаления вкладок, их надо выровнять как единую систему.
3. Часть технических значений уже исправлена в локальном TMDL, но опубликованный сервис может показывать старые значения до публикации PBIP и refresh.
4. Страницы кодеров групп завязаны на `Dim_AdGroup.ag_part*`; в `bi_Dim_AdGroup` пустые значения уже нормализованы, но базовый `Dim_AdGroup` еще содержит пустые строки.
5. VK Ads перенесен не полностью на star-измерения: `banner_name` уже из `Dim_VkBanner`, но `ad_plan_name/ad_group_name` все еще используются как поля факта.

## Технические значения

Live ClickHouse сейчас еще содержит технические значения:

| Таблица/поле | Сейчас в live |
|---|---|
| `Dim_AdNetworkType.AdNetworkType` | `AD_NETWORK`, `SEARCH`, `Звонки`, `Отзывы` |
| `Dim_Campaign.campaign_status` | `MODERATION`, `REJECTED`, пусто, `NULL`, `Активна`, `Остановлена` |
| `Dim_Campaign.payment_model` | `CPA`, `CPC`, `NULL` |
| `fact_adformat_spend.ad_format` | `IMAGE`, `TEXT`, `SMART_SINGLE`, `VIDEO`, `multicard` |

Но в локальном BA6 TMDL уже есть PBI-слой перевода:

- `Dim_AdNetworkType.tmdl`: `AD_NETWORK -> РСЯ`, `SEARCH -> Поиск`.
- `Dim_Campaign.tmdl`: `MODERATION -> На модерации`, `REJECTED -> Отклонена`, `CPA -> за конверсии`, `CPC -> за клики`, пусто/NULL -> `Не указана`.
- `Dim_AdFormat.tmdl`: `IMAGE -> графический`, `TEXT -> текстовый (ТГО)`, `SMART_SINGLE -> смарт-баннер`, `VIDEO -> видео`, `multicard -> комбинаторное объявление`.

После публикации текущего PBIP и refresh эти срезы должны стать русскими без второго pipeline. Если английский останется, значит конкретный визуал тянет не переведенную колонку.

Затронутые страницы:

- `Dim_AdNetworkType.AdNetworkType` используется на 42 страницах.
- `Dim_Campaign.campaign_status` используется на 44 страницах.
- `Dim_Campaign.payment_model` используется на 46 страницах.
- `fact_adformat_spend.ad_format` используется на странице `Я.Директ формат`.

## Пустые строки в кодерах групп

Страницы BA6 используют `Dim_AdGroup.ag_part*`:

- `Я.Директ Кодер группы CT1`
- `Я.Директ Кодер группы A/N/G`
- `Я.Директ Кодер группы CT2/AG`
- `Я.Директ Кодер группы R`
- `Я.Директ марки авто`
- `Я.Директ проверки ошибки в кодере`

Проверка live:

- `Dim_AdGroup`: 399 346 строк с пустыми `ag_part1/ag_part2/ag_part3`.
- `bi_Dim_AdGroup`: 0 пустых, пустые заменены на `Не указано`.
- Через `pbi_big_analytics_full -> Dim_AdGroup` пустой блок дает 567 580 строк и 395 989 976,48 ₽.

Решение:

1. После публикации/refresh проверить, что BI реально читает `bi_Dim_AdGroup` и показывает `Не указано`, а не пустые строки.
2. Если пустые строки останутся, проверить relationship/lineage на визуалах `Dim_AdGroup.ag_part*`.
3. Для устойчивости можно также нормализовать базовый `Dim_AdGroup`, но минимальный фикс для экрана уже находится в `bi_Dim_AdGroup`/TMDL.

## Месяц на странице `Общая недели`

В опубликованном сервисе был скрин, где месяц показан номером.

Локальный BA6 уже отличается от BA5:

- BA5 `Dim_Date[Месяц]` был числовым `sourceColumn: month`.
- BA6 `Dim_Date[Месяц]` уже DAX: `1 -> январь`, ..., `12 -> декабрь`, с сортировкой по скрытому `Месяц_номер`.

Решение: это должно исправиться публикацией текущего PBIP и refresh, без pipeline. Проверить страницу `Общая недели` после обновления.

## VK Ads

BA5 показывал:

- `fact_vk_ads.ad_plan_name`
- `fact_vk_ads.ad_group_name`
- `fact_vk_ads.banner_name`

BA6 показывает:

- `fact_vk_ads.ad_plan_name`
- `fact_vk_ads.ad_group_name`
- `Dim_VkBanner.banner_name`

В модели BA6 уже есть relationships:

- `fact_vk_ads.ad_plan_id -> Dim_VkAdPlan.ad_plan_id`
- `fact_vk_ads.ad_group_id -> Dim_VkAdGroup.ad_group_id`
- `fact_vk_ads.banner_id -> Dim_VkBanner.banner_id`

Решение: перевести страницу VK Ads до конца на star-поля:

- `Dim_VkAdPlan.ad_plan_name`
- `Dim_VkAdGroup.ad_group_name`
- `Dim_VkBanner.banner_name`

Это должно убрать странное поведение фильтров, где выбор `тип_сайта`/регион оставляет нулевые или пустые комбинации планов.

## Приемка после публикации PBIP

Проверить без второго pipeline:

1. `pages.json` не содержит отсутствующих id `a9dc...`, `2fae...`, `a7ff...`.
2. В `тип кампании` нет `AD_NETWORK/SEARCH`, есть `РСЯ/Поиск`.
3. В `статус кампаний` нет `MODERATION/REJECTED`, есть `На модерации/Отклонена/Не указана`.
4. В `тип оплаты` нет `CPA/CPC`, есть `за конверсии/за клики/Не указана`.
5. В `Я.Директ формат` нет `IMAGE/TEXT/SMART_SINGLE/VIDEO/multicard`.
6. На страницах `ag_part*` пустые строки заменены на `Не указано`.
7. `Общая недели` показывает названия месяцев, не номера.
8. `VK Ads` фильтры по `тип_сайта`, `регион`, `салон` не оставляют старые нулевые строки.
