## 🔑🔑 ГЛАВНЫЙ ВЫВОД ПО ВОРОНКЕ (доменная сверка, 2026-06-02)

**Воронку приездов/продаж нужно сверять ПО ДОМЕНАМ с `big_analytics_full_arrival` (BFA), а НЕ с BAF и НЕ по строке «ОБЩЕЕ».**

Колонка `domain` (чистый домен, без протокола) есть в ОБЕИХ таблицах BAF и BFA, заполнена на **100%**. В Sheets домены лежат в подтаблице **«Сайты»**.

При матче по домену на BFA воронка приездов **СХОДИТСЯ** для салонов с чистым CRM-фидом:
- АвтоСтайл +4%, Кит-Авто −2%, Казань +1%, АвтоЦентрСити −0% ✅

**Почему нельзя сверять домены с BAF:** BAF суммирует воронку по ВСЕМ `_source_table` на домен → задвоение. Главный виновник — `пиксель` + `пиксель_атрибуц` (одинаковые kval/priezd в двух моделях атрибуции, **нельзя суммировать**) + direct/calls/seo несут свои копии. Пример `autocenter-stav.ru` 2026-01: Sheets priezd=48, **BFA=50 (−4% ✅)**, BAF=100 (=2×, пиксель 22 + пиксель_атрибуц 22 дубль + direct_zero 33 + calls 21). Прежнее «Sheets >> BFA +20…+150%» было артефактом анкера по строке «ОБЩЕЕ» (все агентства), а не по доменам.

**Прежний «naming-mismatch Лидер» оказался SALON-SPLIT:** в БД ДВА разных салона — «Лидер» (домены Сургут/ХМАО: surgut-autos.ru, havalpark-86.ru, acleader.ru, autopark-surgut.ru — это пиксель-кейс) и «Лидер Авто НСК» (Новосибирск: ac-hmelnitsky.ru, nsk-*). Лист «Лидер Авто НСК Сводная» содержит только НСК-домены; Сургут-домены «Лидер» в этих 8 листах отсутствуют (другой лист).

**Реальные расхождения на стороне Sheets «Сайты»** (не баг BAF/BFA): Лидер НСК и Автопарк Южный — Sheets «Сайты» показывает ~50-75% от CRM-приездов (`ac-hmelnitsky.ru` 2026-04: Sheets 31 / BFA 63 — Sheets недосчитывает ~2×).

Детали — в разделе «ЗАДАЧА 6в» ниже.

## 🔑 ГЛАВНЫЙ ВЫВОД СЕССИИ 2026-06-02

**Прежние «расхождения» по контексту (−55%, +27%, −40%) и по пикселю (−45…−100%) оказались АРТЕФАКТАМИ ПАРСИНГА, а не ошибками в `big_analytics_full`.**

Причина: сравнивали **широкую summary-строку** листа (которая включает другие агентства / весь лидген) с **узким каналом BAF**. При сверке ОДИНАКОВЫХ сущностей (правильная строка ↔ правильный канал) — **расходы сходятся помесячно** по всем 8 салонам.

Структурных багов в BAF по расходам нет. Осталась горстка точечных выбросов (см. ниже) — все объяснены (пробел фида / методология цены / naming онбординга), не баги расчёта BAF.

- `LeadV ONE Автопарк Южный` ≈ `LeadV ONE Южный Обход`

| Пиксель | все этапы | Sheets **+80…+900%** ❌ | SCOPE-MISMATCH: Sheets `Виктори лиды`=весь лидген, BAF пиксель узкий |

### Вывод по воронке (big_analytics_full)
1. **Контекст leads-этап сходится** (±10-25%). `kval` и `dobro` системно расходятся (Sheets выше) — **разная семантика квалификации статусов**, а не потеря заявок в BAF.
2. **Пиксель и посевы НЕ сопоставимы 1:1** — разный охват строк Sheets и каналов BAF по определению (пиксель: Sheets шире; посевы: Sheets уже). Структурное решение, не баг.
3. **Инвариант воронки BAF чист.**
4. Combo-листы (АЦ Карплаза, Мас Моторс) — контекст+пиксель слиты, воронка по источникам не раскладывается.
