# data_verification — как проверять данные big_analytics_v5 и какие бывают ошибки

> База знаний по **сверке/верификации** витрины `big_analytics_full` и посевов.
> Это не код проверок (он в `data_check/`, `step12_proverka_big_analytics/`,
> `crm_mappings_check/`), а **накопленное знание**: методология сверки, найденные
> расхождения, какие из них баги, а какие — артефакты парсинга, и как не разбираться
> с нуля в следующий раз.
>
> 👉 При задаче «проверь данные / расход не сходится / воронка плавает / посевы» —
> читать ОТСЮДА, прежде чем лезть в SQL.
