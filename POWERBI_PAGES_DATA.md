## Страницы

| Блок | Статус BA6 | Примечание |
|---|---|---|
| `Общая` | активен | Месяцы должны сортироваться календарно через `Dim_Date[Месяц_номер]`, не по алфавиту. |
| `Я.Директ` | активен | Верхнее меню должно повторять BA5 по координатам и видимым подписям. |
| `Я.Директ type placement` | активен | Фильтры должны быть выпадающими списками, как на остальных страницах. |
| `Я.Директ_кодер кампании/кампании` | активен | Поле `номер кампании | название кампании` должно показывать статусный префикс кампании. |
| `Я.Директ_марки авто` | удален | Кнопку верхнего меню и саму страницу не возвращать. |
| `Я.Директ площадки РСЯ` | скрыт/ограничен | Это не BA5-фиды: настоящей расходной таблицы по `feed_id` в BA6 нет. |
| `VK ads` | активен | Страница должна читать star-измерения, а не смешивать их с текстами из факта. |

## Контракт корректировок

- Для расходных фактов `fact_region_spend`, `fact_adformat_spend`, `fact_criterion_spend`
  директолог после даты ручной корректировки не должен возвращаться из бездатного
  `gsheet_sites.directologist`.
- Для заявочной и визитной осей действует то же правило: fallback специалиста не должен
  заново подставлять старого директолога из доменного справочника после даты корректировки.
- Ручные даты корректировок лежат в `corrections.py`; при добавлении новой даты нужно обновить
  тест `tests/test_star_refactor_contracts.py::test_spend_facts_use_dated_specialist_mapping`.
- В разборе `ag_part*` строки `tp6`/`tp7` с пустым `adgroup_code` должны попадать в `MK/TK`.

## Приемка после публикации

1. На страницах с месяцем порядок январь -> декабрь, а не алфавит.
2. На верхних меню видны полные подписи кнопок; `Очистить все срезы` не перекрывает срезы.
3. На `type placement` фильтры работают как выпадающие списки.
4. Страницы и кнопки `Я.Директ_марки авто` нет.
5. На страницах кодеров `tp6`/`tp7` показывают `MK/TK`, если кодер группы пустой.
6. В расходных отчетах после даты корректировки не появляется старый директолог.
7. В срезе `номер кампании | название кампании` видны статусные префиксы: зеленый для активных,
   желтый для черновиков/модерации, красный для остановленных/отклоненных/архива.
