## Контракт корректировок

- BA6 Power BI рассматривает только нишу `Авто`. Не-авто ниши не добавляются в BI-страницы,
  измерения и срезы.
- На страницах `Я.Директ` фильтр `специалист` должен содержать только активный список:
  `Вильцин Константин`, `Гордеева Наталья`, `Зубакин Алексей`, `Ильин Данил`,
  `Караваев Михаил`, `Крючкова Елизавета`, `Немытова Валерия`, `Павлов Алексей`,
  `Питеркина Дарья`, `Саламахин Иван`, `Терехов Евгений`, `Тумашенко Евгений`,
  `Щербакова Наталья`.
- Уволенные из корректировок (`Кудерко Семен`, `Сергеев Алексей`, `Николай`,
  `Чепелев Никита`) не должны появляться в выпадающем списке `специалист` только на страницах,
  чей `displayName` начинается с `Я.Директ`. Общие/Отзывы/Посевы этой механической чисткой не
  затрагиваются без отдельной команды.
- Для расходных фактов `fact_region_spend`, `fact_adformat_spend`, `fact_criterion_spend`
  директолог после даты ручной корректировки не должен возвращаться из бездатного
  `gsheet_sites.directologist`.
- Для заявочной и визитной осей действует то же правило: fallback специалиста не должен
  заново подставлять старого директолога из доменного справочника после даты корректировки.
- `Звонки` не является специалистом. Если звонок не удалось привязать к конкретному специалисту
  по домену/аккаунту, поле `специалист` должно оставаться в бакете `Без специалиста`; тип звонка
  хранится в `тип_заявки`/`источник`.
- Ручные даты корректировок лежат в `corrections.py`; при изменении правила нужно обновить тесты
  `test_spend_facts_use_dated_specialist_mapping` и
  `test_claim_and_visit_fallbacks_do_not_restore_stale_directologist_after_cutoff`.
- В разборе `ag_part*` строки `tp6`/`tp7` с пустым `adgroup_code` должны попадать в `MK/TK`.
- В PBIP `Dim_Campaign[cpc_cpa]` отображается как `cpc`/`cpa`, а не как `за клики`/`за конверсии`.
- В PBIP `big_analytics_full[доменная зона]`: пиксельные строки показывают `пиксель`, прочие пустые/невалидные домены показывают `без домена`.
- В PBIP страницы текстов объявлений берут `title/status/ad_type/text` из `Dim_AdText`, а факт `yandex_direct_ads_texts` остается таблицей метрик.
- В PBIP `yandex_direct_ads_texts[date]` и `yandex_direct_search_query_report_master[date]` считаются от `loaded_at` для совместимости со старыми visual-срезами.
- В `bi_yandex_direct_type_placement_report_master[type_placement_ru]`
  `SERVICE_GALLERY_POSITION_TYPE` переводится как `Сервисная галерея`.
- В `campaign_status` состояние кампании важнее общего статуса: `ARCHIVED` -> `Архив`,
  `SUSPENDED/OFF/STOPPED` -> `Остановлена`. `Активна` допускается только для
  `ACCEPTED/ACTIVE` + `state=ON` и только если логин есть в активных авто-аккаунтах
  `reference_data.gsheet_sites` (`niche='Авто'`, `status='Контекст активно'`).
- Воронка в визуалах должна сохранять порядок этапов:
  `Обращения -> Заявки -> Квал -> Приезд/Визит -> ДО -> Одобрено -> Продажи`.
  Каждый следующий количественный этап не должен быть больше предыдущего; `CR`-колонки держатся
  в общем правом блоке CR.

## Приемка после публикации

1. На страницах с месяцем порядок январь -> декабрь, а не алфавит.
2. На верхних меню видны полные подписи кнопок; `Очистить все срезы` не перекрывает срезы.
3. На `type placement` фильтры работают как выпадающие списки.
4. Страницы и кнопки `Я.Директ_марки авто` нет.
5. Страницы и кнопки `Я.Директ_минус-фразы` нет.
6. В таблицах/матрицах нет столбцов `CRM: заказ отменен`, `CPL CRM: заказ отменен`,
   `CRM: спам-заказ`, `CPL CRM: спам-заказ`.
7. На страницах кодеров `tp6`/`tp7` показывают `MK/TK`, если кодер группы пустой.
8. В расходных отчетах после даты корректировки не появляется старый директолог.
9. В сводных по специалисту нет строки `Звонки`.
10. В срезе `номер кампании | название кампании` видны статусные префиксы: зеленый для активных,
   желтый для черновиков/модерации, красный для остановленных/отклоненных/архива.
11. В срезах пустые строки сведены к одному системному значению Power BI `(Пусто)`;
    строковое значение `"(пусто)"` в модель не добавляется.
12. В `доменная зона` нет пустой строки: только `пиксель`, `без домена` или доменная зона вида `.ru`.
13. На `type placement` нет строки `SERVICE_GALLERY_POSITION_TYPE`; вместо нее видна `Сервисная галерея`.
14. В admin/user есть страница `Общая_логин/aon`, она открывается кнопкой `логин/aon` в верхнем меню
    и показывает только `Dim_AdGroup[ag_part2] = aon - Включены все категории + все настройки брендов или рся`.
15. В фильтре `специалист` на страницах `Я.Директ` есть `Немытова Валерия` и нет уволенных
    директологов из корректировок.
16. В admin/user есть страница `Я.Директ_домен/кампания/группа`, она открывается из верхнего меню
    `Я.Директ`.
17. Фильтр `campaign_status = Активна` не включает кампании со `state` остановки/архива и
    кампании логинов, которых нет среди активных авто-аккаунтов `gsheet_sites`.
