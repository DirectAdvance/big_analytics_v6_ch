## ❗ Что БЛОКИРУЕТСЯ открытым Power BI Desktop (нужно от пользователя)

Эти действия нельзя делать вслепую через TMDL на проде (ошибка = модель не грузится,
необратимо). Делаются руками в открытом Power BI Desktop по чек-листу `02_*`:

1. **Открыть Power BI Desktop** с моделью `Большая аналитика_v00` (СНАЧАЛА сделать копию файла).
2. **Сообщить точные параметры источника** из текущего M-запроса `big_analytics_full`:
   как именно прописан Source — `PostgreSQL.Database("host","db")` или ODBC/Sql.Database,
   хост/порт. Нужно, чтобы M-запросы dim были в том же формате (`#"PG.Database"` в `01_*`).
3. **Завести 4 dim** (Power Query → PostgreSQL → схема `star`) — Этап 1 чек-листа.
4. **Перенацелить partition `big_analytics_full`** на `star.fact_big_analytics` — Этап 2.
5. **Создать 8 связей** drag-drop (single-direction, dim 1→* факт) — Этап 4.
6. **Перенести ~630 ссылок полей** факт→dim по 37 страницам — Этап 5
   (сначала запустить `find_field_refs.py` на папке `*.Report` → получить CSV-карту).
7. **Сверить с эталоном** (priezd 34157 / prodazhi 2384 / cost 854 755 512.77; визита 42979/2838)
   и **опубликовать** — Этапы 7–8.
